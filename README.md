# ConnectHub

A modern social media web application built with **Next.js**, **React**, **TypeScript**, and **Tailwind CSS**.

This project was created as a frontend prototype to demonstrate responsive UI design, reusable React components, clean folder structure, and modern development practices.

---

## Features

- Responsive Landing Page
- User Authentication UI
- Home Feed
- Create Post
- Profile Page
- Messages Page
- Notifications Page
- Reusable Components
- Modern UI with Tailwind CSS
- Clean Project Structure

---

## Tech Stack

- Next.js 15+
- React
- TypeScript
- Tailwind CSS
- Lucide React Icons

## Getting Started

### Install dependencies

```bash
npm install
```

### Run development server

```bash
npm run dev
```

Open

```
http://localhost:3000
```

---

## Build Project

```bash
npm run build
```

---

## Run Production

```bash
npm start
```
