# 🌐 ConnectHub - Social Media SaaS Platform

A modern and responsive Social Media SaaS platform built using **Next.js 16**, **TypeScript**, and **Tailwind CSS**. The project demonstrates reusable component architecture, responsive UI design, GitHub Actions CI pipeline, and Vercel deployment.

# ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/Pk7372singh/GlobalCo.git
```

Go to project

```bash
cd GlobalCo
```

Install packages

```bash
npm install
```

Run locally

```bash
npm run dev
```

Open

```
http://localhost:3000
```

---

# 🔄 CI/CD Pipeline

GitHub Actions automatically runs whenever code is pushed to the **main** branch.

Pipeline includes:

- Install Dependencies
- ESLint Check
- Build Next.js Project
- Verify Build Success

Workflow File

```
.github/workflows/ci.yml
```
